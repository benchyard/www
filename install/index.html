Install

Linux amd64 or arm64, Docker Engine 27 or newer with Compose v2, Python 3, Cosign, and root access for the final installation are required.

For a small single-host installation, start with 4 CPU cores, 8 GiB RAM, and 40 GiB free storage. Worker capacity and repository size may require more.

Console

curl -fsSL https://hero.benchyard.com/install.sh | sh -s -- --version 0.1.0 console

Worker

curl -fsSL https://hero.benchyard.com/install.sh | sh -s -- --version 0.1.0 worker

Audit before execution

curl -fsSLo install.sh https://hero.benchyard.com/install.sh
less install.sh
sh install.sh --version 0.1.0 --dry-run console
sudo sh install.sh --version 0.1.0 console

The bootstrap downloads the signed release manifest, verifies its GitHub Actions keyless signature with Cosign, downloads the matching CLI, verifies SHA-256, and then starts installation. Existing environment files are not overwritten.

Official images are public at ghcr.io/benchyard. The installed manifest records immutable image digests; latest is discovery only.
