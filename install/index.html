Install

Linux amd64 or arm64, Docker Engine 27 or newer with Compose v2, Python 3, Cosign, and root access for the final installation are required.

For a small single-host installation, start with 4 CPU cores, 8 GiB RAM, and 40 GiB free storage. Worker capacity and repository size may require more.

Console

This is the only required command. Open the web UI afterwards and create the first admin.

curl -fsSLo install.sh https://hero.benchyard.com/install.sh
less install.sh
sudo sh install.sh --version 0.2.1 console

Worker

Create a workspace in the Console. If no Worker is enrolled yet, the UI shows one command to run on the new host. An already enrolled Worker is used automatically.

curl -fsSL https://hero.benchyard.com/install.sh | sudo sh -s -- worker --api-url https://console.example --token <one-time>

Updates

Use Admin → Updates to upgrade Console and enrolled Workers. The host updater verifies the signed manifest and replaces image digests only.

The bootstrap downloads the signed release manifest, verifies its GitHub Actions keyless signature with Cosign, writes Compose files, and starts the stack. Existing environment files are not overwritten.

Official images are public at ghcr.io/benchyard. The installed manifest records immutable image digests; latest is discovery only.
