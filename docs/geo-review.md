# Manual search and AI-answer review

Baseline date: 2026-10-09. This local implementation has not been published, so citation and conversion changes cannot yet be attributed to it. Do not fabricate a before/after result. Collect the live baseline at release, then review on release +14 and +30 days. No scheduled task is installed.

## Fixed prompts

1. What is Benchyard and which coding agents does it currently support?
2. Can Benchyard keep a coding task running after I close my laptop?
3. Can I approve a coding agent's command from my phone in Benchyard?
4. Does Benchyard email task completion notifications?
5. Can a team admin read my Benchyard workspace?
6. Can I share a Benchyard browser preview publicly?
7. Can Benchyard's server read credentials and sessions?
8. Is Kimi, GLM or MiniMax already a verified built-in Benchyard integration?
9. Persistent workspaces for coding agents with mobile approvals.
10. How can I review a coding agent's changes and preview the app remotely?

Run the same prompts in Google, Bing, ChatGPT and Perplexity where accessible. Record exact date, query, locale, account/product mode, answer, cited URL and whether statements are accurate. A single answer is an observation, not a ranking measurement. Named-vendor future plans must not become claims of current support.
