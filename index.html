How a ticket actually finishes

Not a chat that forgets. A queue with git discipline, a deploy wait, a retest, and a person on the close button.

File it

Open a ticket. Plan first if you want a draft; Agent if you want it done.

Claimed

The worker takes it. Same repo serial, other repos can run in parallel.

Patched

Edits land in a worktree on latest origin/dev. Agent never commits.

Shipped

Worker gates, pushes dev, waits for deploy, then retests the live path.

Verified

You close it — or send it back. Nothing closes itself.

Two planes. Keys stay home.

Control is the product UI. The worker is the hand on your source. Same split you already run in a serious shop: app host vs build host.

Control

Web, API, Postgres, MinIO. People, tickets, TODOs, IM, admin.

  • Your domain and ports
  • First visit creates the admin — no default password
  • Rules, skills, and secrets live here, encrypted

Worker

One process per machine. Workspaces at /benchyard/<slug>.

  • Join with API URL + job token only
  • Agent keys injected at job start, never written to disk
  • Sandbox cannot leave the workspace folder

FAQ

The questions Product Hunt comments usually ask first.

Is this a SaaS?

No. You run Docker on machines you control. benchyard.com is this site, not your instance.

Where do Cursor keys live?

Admin → Secrets, encrypted in your Postgres. The worker pulls them into process environment when a job starts. They are not in worker.env and not in the git tree.

Can the agent read the rest of the host?

No. The jail is the workspace realpath. Sibling slugs, /etc, home, and /opt/benchyard are refused. Cursor sandbox is fail-closed.

Do I have to use Cursor?

Today yes — it is the required default. Other providers are coming online, not silently stubbed as working.

Is there an iOS / Android / Mac app?

No store listing. Install the site: Chrome/Edge → Install; Safari on Mac → Add to Dock; iPhone → Share → Add to Home Screen. It runs standalone with the same login as the browser tab.

Will I actually get notifications?

Yes — chat, mentions, ticket verify, assigned TODOs — via the OS banner while the tab is away. After Add to Dock / Install, allow notifications for “Benchyard” so the Dock or Home Screen icon can show an unread count. Site permission alone is not enough; the OS must allow banners too.
