Workspace context

Not a blank chat.

The agent sees this workspace: docs, repos, attachments. Switching slug changes the root. It cannot wander the host.

  • Jail = realpath /benchyard/<slug>. Sibling workspaces are another product tree.
  • Sandbox fail-closed. If Cursor cannot open the sandbox, the job is refused.
  • Docs and other repos in the same slug are readable. /etc, home, and /opt/benchyard are not.

FAQ

Is this a SaaS?

No. You run Docker on machines you control. This site is not your instance. Domain and TLS are yours.

How is this different from Cursor on a laptop?

Cursor is a personal session. Benchyard is the team bench: shared IM, human TODOs, workspace docs, a job queue, and a Worker that runs the agent on your metal — then a person still closes.

Where do agent keys live?

Admin → Secrets, encrypted in your Postgres. Injected when a job starts. Not in worker.env, not in git.

Can the agent read the host?

No. Jail is the workspace realpath. Cursor sandbox is required; if it will not open, the job is refused.
