FAQ

Is this a SaaS?

No. You run Docker on machines you operate. This site is not your instance. Domain and TLS are yours.

How is this different from Cursor on a laptop?

Cursor is a personal session. Benchyard is the team bench: shared IM, human TODOs, workspace docs, a job queue, and a Worker that runs the agent on your metal — then a person still closes.

Where do agent keys live?

Admin → Secrets, encrypted in your Console database with a dedicated master key. They are injected only into the assigned Worker while a job runs. Console administrators and the Console host are trusted and can decrypt them.

Can the agent read the host?

The agent is constrained to the assigned workspace by path checks, the Cursor sandbox, and container hardening. A Worker host administrator remains trusted. If the sandbox cannot start, the job is refused.

Is Benchyard open source?

Benchyard Console and its Worker protocol are Apache-2.0 open source. The Worker implementation is closed source, with free official images available from public GHCR.
