Security

Benchyard is self-hosted. Security starts with an explicit trust boundary, not a hidden Worker implementation.

Trusted boundary

Your Console host, its administrators, PostgreSQL, MinIO, and Worker host administrators are trusted. Console stores Agent secrets encrypted with a dedicated master key and injects them only into the assigned Worker for a job. This is not end-to-end encryption.

Worker isolation

Each job is scoped to an assigned workspace. Canonical-path checks, the coding-agent sandbox, process isolation, and container hardening are separate defense layers. A stale job lease cannot authorize a later state change.

Open and closed components

Console and the Worker protocol are Apache-2.0 open source. Worker source is private, while signed official images are publicly downloadable. No security mechanism relies on the implementation being secret.

Report a vulnerability

Use the private security-advisory flow on GitHub or email security@benchyard.com.
